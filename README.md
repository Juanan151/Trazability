Esta memoria recoge el desarrollo de un sistema de trazabilidad utilizando para
ello la tecnología Blockchain (en este caso, Hyperledger Besu) y los dispositivos IoT
(Internet of Things). Se simulará el trazado del camino que siguen los alimentos hasta
llegar al consumidor aprovechando la versatilidad de los dispositivos IoT para tomar
multitud de datos como la posición geográfica, la temperatura a la que es sometida el
producto, la luminosidad, etc; y algunas de las características de la tecnología Block-
chain que aportan lo más necesario para una trazabilidad segura y fiable. Fiabilidad,
sin duda, lo más importante en este contexto. ¿Como la aporta? Pues porque todo lo
que se añade a la cadena de bloques no se puede modificar; la cadena es inmutable,
la traza es INMUTABLE.
